# YUVA Internship – Week 3
## Unsupervised Learning and Clustering Analysis

### Project Overview
This project focuses on customer segmentation using unsupervised machine learning techniques. The UCI Wholesale Customers dataset is analysed to identify customer groups based on their annual spending patterns.

### Dataset
- Dataset: Wholesale Customers
- Source: UCI Machine Learning Repository
- Records: 440 customers
- Features: Fresh, Milk, Grocery, Frozen, Detergents_Paper and Delicassen

### Tools and Technologies
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- PCA

### Methodology
1. Data loading and inspection
2. Data preprocessing
3. Feature selection and standardization
4. K-Means clustering
5. Elbow method and silhouette analysis
6. Principal Component Analysis (PCA)
7. Hierarchical clustering
8. Cluster profiling and comparison

### Project Files
- Python Jupyter Notebook
- Clustered customer dataset
- Cluster profile CSV
- Model comparison CSV
- Visualization charts
- Detailed project report

### Learning Outcomes
Practical understanding of unsupervised learning, customer segmentation, clustering algorithms, dimensionality reduction and model evaluation.
